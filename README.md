# R.A.T.S.

Raiders' Authority on Temporary Storage is a Vercel-ready recruitment homepage for an ARC Raiders player organization.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build for Vercel.
- `npm run start` serves the production build locally.
- `npm run lint` runs ESLint.
- `npm run typecheck` runs TypeScript without emitting files.

## Deployment

Import this repository in Vercel and use the default Next.js settings. Vercel will install dependencies and run `npm run build`.
